# D&D Wiki — сайт для вашей кампании

Vite + React + TypeScript + Tailwind, бэкенд — Supabase (Auth, Postgres, Storage, RLS), хостинг — GitHub Pages.
Всё бесплатно, без ИИ-токенов. После деплоя работает без вашего участия.

## Как устроен доступ
- **DM** видит и правит всё. **Игрок** видит только записи со статусом `released` — это обеспечивает RLS в базе, а не интерфейс.
- «Секрет DM» хранится в отдельной таблице `entry_secrets`, к которой у игроков нет доступа вообще, даже у released-записей.
- Картинки лежат в приватном бакете; файл отдаётся (по временной ссылке) только если запись released или запрашивает DM.
- Первый зарегистрированный пользователь автоматически становится DM. Дополнительно можно заранее вписать email в таблицу `dm_emails`.
- Роли меняются в Админка → Игроки. Последнего DM снять нельзя.

## Установка (≈15 минут)

### 1. Supabase
1. Создайте проект на https://supabase.com (Free).
2. SQL Editor → вставьте весь файл `supabase/schema.sql` → Run. **Сделайте это до регистрации.**
3. (Необязательно) чтобы DM назначался по почте: `insert into public.dm_emails values ('вы@почта.com');` — выполнить до регистрации.
4. Settings → API: скопируйте **Project URL** и **anon public key**.
5. Authentication → URL Configuration: в **Site URL** и **Redirect URLs** добавьте адрес сайта
   `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/` (и `http://localhost:5173/` для локальной разработки).
6. (Удобно для друзей) Authentication → Providers → Email: можно выключить «Confirm email», тогда регистрация по паролю сразу пускает внутрь.

### 2. GitHub
1. Создайте репозиторий, загрузите в него содержимое этой папки (ветка `main`).
2. Settings → Secrets and variables → Actions → **Secrets**: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`.
   В **Variables** (необязательно): `VITE_SITE_NAME` — название сайта.
3. Settings → Pages → Source: **GitHub Actions**.
4. Любой push в `main` пересобирает и публикует сайт. Адрес: `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`.

### 3. Первый вход
Откройте сайт и **зарегистрируйтесь первым** — вы станете DM. Дальше раздайте ссылку игрокам.

## Локальная разработка
```
cp .env.example .env     # впишите ключи
npm install
npm run dev
```

## Важно знать
- **Supabase Free усыпляет проект после 7 дней без запросов.** Workflow `keepalive.yml` раз в 3 дня будит базу
  (использует те же секреты). GitHub отключает scheduled-workflows после 60 дней без коммитов в репозиторий —
  если сайт заснул, зайдите в Actions и включите workflow или сделайте любой коммит; базу можно восстановить кнопкой Restore в Supabase.
- Лимиты Free: 1 ГБ файлов, 500 МБ базы. Картинки автоматически сжимаются до 1600 px (WebP).
- Anon key публичный по замыслу Supabase: безопасность держится на RLS-политиках из `schema.sql`.

## Структура
```
supabase/schema.sql        таблицы, RLS, триггеры, Storage, начальные разделы
.github/workflows/         deploy.yml (Pages), keepalive.yml
src/lib/                   supabase-клиент, авторизация, картинки, утилиты
src/pages/                 Главная, Все записи (поиск/фильтры), Запись, Редактор, Инвентарь, Админка
src/admin/                 Заявки, Записи, Разделы (создание/переименование/порядок/удаление), Игроки
```
